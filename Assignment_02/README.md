# CampusWheels Vehicle Rental

This project is a simple Object-Oriented Programming assignment for managing vehicles and renters at a campus vehicle-rental desk.

## Files
- `rental.py` — contains the `Vehicle`, `Renter`, `ElectricCar`, and `Motorbike` classes.
- `main.py` — demonstrates creating vehicles, renting and returning them, and handling invalid input.
- `README.md` — project instructions and AI-use note.

## How to run
1. Open a terminal in the Assignment_02 folder.
2. Run:
   ```bash
   python3 main.py
   ```

## OOP concepts used
- Classes and objects
- Encapsulation with validation in the `Renter` property setters
- Inheritance from `Vehicle`
- Polymorphism through different `__str__` outputs for each vehicle type
